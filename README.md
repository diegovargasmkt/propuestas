# Propuestas

Repositorio público de propuestas estratégicas y presentaciones ejecutivas.

Cada propuesta vive en su propia carpeta y se publica automáticamente en GitHub Pages.

## Propuestas

- [AUNAP — Juan Rodrigo Alvarado](https://diegovargasmkt.github.io/propuestas/aunap-alvarado/)

## Cómo agregar una nueva propuesta

1. Crea una carpeta con el nombre de la propuesta
2. Agrega un `index.html` autocontenido
3. Actualiza la portada en `index.html`
4. Haz commit y push — GitHub Pages lo publica automáticamente
